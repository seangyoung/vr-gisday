# GIS Day promo screenshots

Five 1000 × 750 JPEG crops from the app's local desktop scene preview:

1. `01-stand-inside-the-layers.jpg` — landscape with topography, vegetation, water, roads, and the layer clipboard.
2. `02-make-the-world-flat.jpg` — globe, Mercator map, and Tissot circles.
3. `03-scan-the-hidden-world.jpg` — synthetic bridge point cloud after scans from two sides.
4. `04-see-the-invisible.jpg` — London Landsat false-color scene. Image credit: NASA Earth Observatory images by Robert Simmon, using Landsat data from the USGS Global Visualization Viewer.
5. `05-what-changed.jpg` — Illinois/Indiana flood comparison. Image credit: U.S. Geological Survey, Landsat 5 imagery.

`contact-sheet.jpg` is a quick overview; `vr-gisday-promo-screenshots.zip` contains the five numbered crops. The `source/` directory retains the full 1600 × 900 preview captures, including two additional unselected scenes. The five promo crops remove the development-only control strip by cropping; they do not alter the rendered lesson content. These are desktop preview captures of the WebXR scenes, not in-headset photographs. For imagery details and original source links, see [`SOURCES.md`](../SOURCES.md).
